# 🖋️ Lumina Journal — Personal Editorial & Blogging Studio

A complete, production-quality personal blogging platform and writing studio built with modern web technologies.

## ✨ Features

- **Editorial Reading Experience:** Custom typography, reading progress indicator, dynamic scroll-spy Table of Contents, appreciation counter, and social sharing.
- **Full Writing Studio:** Powered by TipTap rich text editor with support for headings, code blocks, tables, blockquotes, formatting, and images.
- **Autosave System:** Non-blocking automatic saving of drafts to persistent storage with recovery protection.
- **High-Fidelity Preview Mode:** Live preview that matches the public reader view with floating studio controls.
- **Studio Dashboard & Analytics:** Metric widgets, readership trajectory chart, article status management (Publish, Unpublish, Duplicate, Delete).
- **Light & Dark Mode:** Curated editorial color scheme with smooth transitions and persistent state.

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS** + `@tailwindcss/typography`
- **TipTap Rich Text Editor**
- **Lucide React** (Icons)
- **Canvas Confetti**

## 🚀 Getting Started

1. Clone or download the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
